# CutPilot 프론트엔드

Next.js와 React로 만든 영상 편집 화면의 초기 프로토타입입니다.

## 실행

`frontend` 폴더에서 다음 명령을 실행한 뒤 브라우저에서 http://localhost:3000 을 엽니다.

```bash
npm install
npm run dev
```

## 현재 구현

백엔드(`backend`, http://localhost:8000)에 연결되어 있습니다. API 계약은 `docs/api.md`를 참고하세요.

- 영상 업로드 → 서버 분석(사람 추적) → 미리보기는 서버의 가벼운 프록시 영상을 재생
- 채팅으로 편집 계획 전달 (한 문장 또는 "1. … 2. …" 여러 단계, Shift+Enter 줄바꿈)
- 에이전트가 정할 수 없는 것만 하나씩 질문 → 답 버튼, 또는 일시정지 화면의 사람 박스 클릭으로 답
- 작업 리스트: AI가 이해한 계획, 행별 상태(확정 / 확인 필요 / 선택 필요)와 경고
- 질문이 끝나면 최종 명세서 → 승인하면 렌더링 → '완료' 탭에서 결과 재생, 내보내기는 원본 해상도
- 영상 제목 수정
- `?mode=text`: 미리보기 박스를 숨기는 사용자 실험용 "텍스트 전용" 조건

백엔드 주소는 기본 `http://localhost:8000`이며, 다르면 `NEXT_PUBLIC_API_BASE_URL`을 지정합니다.
백엔드에 Gemini 키가 없으면 오프라인 키워드 모드로 동작하고 헤더에 "오프라인 모드"가 표시됩니다.
서버를 재시작하면 대화(세션)는 사라지고 분석한 영상은 남습니다.

`lib/offlineChat.ts`와 백엔드의 `/demo/offline-sessions`(영상 없이 가상 인물로 하는 채팅)는
지금 화면에서는 쓰지 않습니다. 실제 연결이 오프라인 모드를 포함하므로, 필요 없으면 지워도 됩니다.
