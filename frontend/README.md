# CutPilot 프론트엔드

Next.js와 React로 만든 영상 편집 화면의 초기 프로토타입입니다.

## 실행

`frontend` 폴더에서 다음 명령을 실행한 뒤 브라우저에서 http://localhost:3000 을 엽니다.

```bash
npm install
npm run dev
```

## 현재 구현

- 원본 영상 파일을 브라우저에서 선택하고 재생
- 원본/완료 탭과 읽기 전용 완료 화면
- 예시 작업 목록, 삭제, 객체 선택 안내 및 선택 취소
- 백엔드 오프라인 키워드 플래너를 사용하는 채팅 화면
- 작업 목록과 채팅의 독립적인 스크롤

현재 오프라인 채팅에는 가상의 사람 두 명이 사용되며 실제 영상과 연결되지 않습니다. 예를 들어 `person_02 블러`, `3초부터 6초까지`를 입력할 수 있습니다. 백엔드 주소는 기본적으로 `http://localhost:8000`이며, 다른 주소를 사용한다면 `NEXT_PUBLIC_API_BASE_URL`을 지정합니다. 백엔드 재시작 시 대화가 사라집니다.

오프라인 대화에서 계획을 확인하면 작업 목록에 반영됩니다. 현재 목록의 대상은 가상 객체입니다. 객체 탐지·선택, 서버 업로드, Gemini 대화, 렌더링 및 결과 영상은 아직 연결되지 않았습니다. 선택한 원본 영상은 브라우저에서만 재생됩니다.

백엔드 연동 시 `backend/cutpilot/schemas/`의 VideoAsset, Track, EditPlan을 참고해 API 계약을 정합니다. 기존 프론트엔드 계획은 `docs/decisions/0001-initial-stack.md`를 참고하세요.
